# 首个公开预览版的验证范围

版本：`qspi-apps-23`，网络接收窗口修复版，2026-11-15。

合并镜像 SHA-256：

```text
d41f82a4d5c3ffbf3adbaffe7aceaea6d03625f55f6da970f1a677e943fb1a60
```

app 大小 7,528,416 字节；当前 8MiB 应用分区剩余 860,192 字节。板载 Flash 为 16MB，当前并没有把整片空间都分配给 app。

- 已完成 ESP-IDF v5.5.5 构建、三段镜像写入和设备写入哈希校验，启动记录确认桌面及 17 个应用初始化。
- 公开源码中用于当前 app 的 398 项最终覆盖层输入，与该镜像冻结的暂存源码逐字节一致。
- 从公开树重新生成独立暂存项目后，398 项冻结输入再次全部匹配；82 个 Python 文件和 PowerShell 脚本解析通过，公开后端的 26 项离线测试通过。没有在另一台全新电脑重装工具链并重编整个固件。
- 新网络版的 TCP 接收窗口为 32KiB，接收邮箱为 24；哔哩播放期间临时关闭 Wi-Fi modem-sleep，停止时恢复原设置，实际日志见到进入和恢复成功。
- 用户反馈哔哩播放“好多了，还是有点卡，但是比之前流畅多了”。这是明显改善，**不等于持续流畅、稳定 60FPS 或完整回归通过**。
- 最近播放记录实际选择“推荐”码率，不能当作同一 1200kbps 的严格前后对照。
- 触摸连续画线、后台和返回手势在前一版相同实现上由用户确认正常；本地视频声音连续、音画基本同步、双指放大缩小在更早 v22 上确认正常。这些是历史验证范围，不标成当前镜像所有功能都重新验收。
- 扫码登录、个人资料、收藏夹显示有历史用户验证；当前账号状态取决于各自服务端。收藏增删和所有异常路径没有完成全量实机验收。

已知问题与后续计划：

- 哔哩仍可能有卡顿；高画质还受网络、JPEG 解码和屏幕传输共同限制。
- 快速滚动仍可能出现撕裂，当前没有承诺彻底消除。
- 显示 FPS 是软件刷新统计，不是面板扫描频率或光学测量。
- 部分颜文字和 emoji 仍可能缺字；当前采用有界的单色补充字库。
- 星野控制台仍保留开发服务的固定基址，自建需要修改源码并编译。
- 视频列表封面缩略图、小屏 UI 进一步优化和自适应帧率属于后续计划，本发布版未包含。
- 这是开发预览版，尚未完成长时间运行、全部应用组合和全部网络环境验证。

公开包不包含完整 Flash 备份、NVS、账号 Cookie、Wi-Fi 密码、设备令牌、API Key 或原始设备运行日志。
