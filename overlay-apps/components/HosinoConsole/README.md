# 星野控制台原生界面

这是独立注册到 Brookesia 桌面的原生 LVGL 应用。`WHOLE_ARCHIVE` 与
`ESP_UTILS_REGISTER_PLUGIN_WITH_CONSTRUCTOR` 完成注册，不替换主桌面、BSP、
状态栏或全面屏手势。

界面按 `getVisualArea()` 排布，左右各留 40px、底部留 68px。顶部为对话和管理
两页；密码、消息、记忆查询使用单独编辑视图。中文使用 LVGL 拼音候选与
`hosino_chat_font_16`，英文／数字切换会销毁原 IME 后再创建键盘，避免旧候选
回调引用已删除对象。IME 析构拥有键盘和候选面板，因此只显式销毁一次。

所有服务操作由 `hosino_console_client` 实现；界面只提交命令和复制 PSRAM
快照。没有同步 HTTP、串口访问或伪造管理数据。默认不选择、不创建、不发送；
新建设备会话与发送分别需要明确点击。发送按钮以客户端确认的
`send_available` 为准，其他会话显示仅查看提示；不声称 `deliver:false`
能限制模型工具的外发。密码不写入文件或 NVS，也不作为草稿保留。

`pause()` 停轮询并失效旧请求；`close()` 异步 shutdown 网络任务。重新打开时
等待旧任务真正停止才销毁并创建新客户端，界面线程不等待 HTTP，也不硬删任务。
关闭时同时释放 UI 自己的快照与命令缓冲；网络 worker 在退出前主动释放大块
响应、解析、会话缓存和快照，留下退出状态供 UI 下次打开确认。无需依赖已被
Brookesia 删除的 timer 收尾，也不会因快速重开启动两个 worker。
析构以 `release()` 将最后清理交给 worker。UI 定时器在 `run()` 内创建，按
Brookesia 的资源记录规则在关闭时先暂停、清空成员指针，由框架最终删除。
没有后台任务持有 LVGL 对象。页面切换在 GUI timer 中执行，按前台与当前应用
screen 校验；按住按钮期间不重建界面。

首版支持登录、会话浏览／明确新建、最近历史、文字发送／停止，以及只读总览、
模型、用量和记忆查询。长消息及有界列表可能截取，会显示提示；不实现语音、
角色动画、模型切换、图片上传或高危服务设置。发送提交成功并不等于服务器
成功，草稿保留在 RAM，结果不明确时由客户端禁止重复发送并先同步历史。
结果未确认的提示持续显示，普通刷新不会解除；用户核对历史后，关闭并重新
打开应用、重新登录方可继续同一会话。本轮不提供绕过该保护的确认按钮。
非设备会话的发送与停止生成均禁用，历史仍可查看。

验证：首次真实 Xtensa 语法检查已通过 C++ 界面和 C 图标单元（启用拼音与 K9
宏、使用实际 Brookesia/LVGL 头）。整机编译和设备触摸／网络实测由主任务继续，
当前界面不能据语法检查宣称已在硬件验证。
