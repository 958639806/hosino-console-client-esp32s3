# 星野 ESP32 多应用桌面

面向 **Waveshare ESP32-S3-Touch-AMOLED-2.16** 的中文多应用固件，基于 ESP-IDF、ESP-Brookesia 和 LVGL。在一块 480×480 AMOLED 小屏上使用星野控制台、本地音乐与视频、哔哩哔哩、画板和常用工具，同时保留 Brookesia 桌面、状态栏、最近任务及全面屏手势。

项目从微雪官方 `03_esp-brookesia` 示例扩展而来，包含本板适配、中文界面、媒体链路和应用源码。应用可以分别开发，显示、触摸、状态栏和系统导航仍由统一桌面管理。

这是持续开发中的实验固件。当前版本已经在目标板完成构建、刷写和启动；在线视频已有实际音画输出，网络接收优化后体验明显改善，仍存在部分卡顿。功能实现、主机测试通过和用户实机确认在文档中分别记录，不把全部应用都标成已完整验收。

## 适用硬件

仅针对 **ESP32-S3-Touch-AMOLED-2.16**，其他尺寸或同系列开发板需要重新适配。

| 硬件 | 本板资源 |
| --- | --- |
| 主控与存储 | ESP32-S3，双核最高240MHz；16MB Flash、8MB PSRAM |
| 屏幕 | 2.16英寸、480×480 AMOLED，CO5300，QSPI接口 |
| 触摸 | CST9220电容触摸，I2C及中断输入；应用可使用双指手势 |
| 无线 | 2.4GHz Wi-Fi、Bluetooth LE |
| 音频 | ES8311播放、ES7210双麦克风采集；音频数据通过I2S传输 |
| 其他 | AXP2101电源管理、QMI8658 IMU、RTC、microSD卡槽、USB Type-C |

硬件资料见[微雪官方文档](https://docs.waveshare.net/ESP32-S3-Touch-AMOLED-2.16/)。本项目的TF卡使用 **SDMMC 1-bit**，请求40MHz；蓝牙设置目前提供BLE扫描，不支持连接经典蓝牙耳机、音箱或手机蓝牙网络共享。

## 桌面和操作

- 中文应用名称、适合圆角屏的状态栏边距、电池百分比，以及真实内部内存/PSRAM可用量显示。
- 底部上滑返回桌面，上滑并停留进入最近任务；保留原有系统导航，不要求修改排线或硬件。
- 顶部附近显示软件FPS，方便观察界面负载。它是软件提交统计，不等于面板扫描频率。
- 实体按键在星野控制台前台可配置为菜单、返回、输入或录音等快捷操作。
- 触摸路径加入有界释放确认，画板改为固定PSRAM画布及连续笔迹；用户已确认此前版本画线连贯、后台和返回正常。

当前应用版使用显示QSPI **80MHz**。这是总线时钟，不是80Hz面板刷新率，也不保证所有界面60FPS。快速滑动仍可能撕裂。

### 星野控制台

提供QWERTY全键拼音、英文/数字输入，以及常见中文、颜文字和单色Emoji字形。拼音使用基础候选词典，没有手机输入法的整句预测；复杂Emoji组合也不能保证完整显示。

语音入口是“录音→服务端语音识别→填入草稿”，由用户核对后发送。它需要另行配置兼容服务和MiMo等服务端识别接口；API Key留在服务端。**当前不含实时语音对话、TTS、角色立绘或角色动画。**

注意：当前控制台源码仍连接开发者的固定服务地址。面向自建服务需配置/替换控制台基址及配对页，不能仅修改Bili设置来切换它。公开版本的具体配置入口应以发布说明为准。

### 哔哩哔哩

ESP32不直接承担H.264在线解码。桥接服务获取原始音视频并使用适配过的FFmpeg转成设备支持的MJPEG视频与PCM音频，通过HTTPS提供给设备。

- 两档目标：标清 **320×180/20FPS**、清晰 **480×270/15FPS**。
- 视频平均预算：**800 / 1200 / 1800 / 2500 / 3500kbps**，另有“推荐”。音频和网络开销另计。
- “推荐”按清晰度使用默认预算和短样本质量选择，**不是实时自适应码率**。复杂内容在最低JPEG质量下也可能超出低码率预算，此时会明确报错。
- 暂停、跳转和切档通过停止原流、保留位置并新建流实现；恢复需要重新准备，不能保证无缝切换。
- B站账户Cookie留在自建服务端；设备使用独立令牌。正常扫码登录，不需要把B站密码填进ESP32。
- 当前采用文字卡片，**尚未实现封面/头像下载**。

扫码登录、个人信息和收藏夹显示有历史板端确认；这不代表当前镜像已重新完成全部账户验收。收藏增删、自然播完和长时间稳定性仍需验证。B站接口及风控可能改变，桥接不保证所有视频可用。

### TF卡和本地媒体

支持 **FAT32及exFAT、MBR分区**，挂载失败不会自动格式化卡。TF卡用于媒体，不会增加PSRAM或自动扩大应用代码分区。

| 位置 | 内容 |
| --- | --- |
| `/music`，兼容`/Music` | MP3、WAV、FLAC |
| `/photos`，兼容`/Photos` | JPG、JPEG |
| 卡内任意可浏览目录 | MJPEG编码的AVI视频，建议16bit PCM音轨 |
| `/Waveshare/Recordings` | 录音生成的WAV文件 |

视频以实际编码为准：**AVI扩展名并不等于MJPEG**，MPEG-4/Xvid/H.264文件不能直接使用这条本地播放链。FLAC会按当前输出链转换，不是bit-perfect播放。
